## 1. О проекте

**Датасет**: [House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)  

**Лучший результат (RMSE на тесте)**: 0.1259 
(на Kaggle Public Leaderboard)

Задача заключается в прогнозировании цены продажи жилых домов в пригороде Айова. Датасет содержит **79 принзаков**, описывающих дом почти полностью — от площади и количества комнат до качества материалов, расположения дома и его общего состояния.

### 📊 Ключевые характеристики датасета

| Параметр | Значение |
|--------|--------|
| Объектов (домов) | 1460 (обучающая выборка) |
| Признаков | 79 + целевая переменная (`SalePrice`) |
| Целевая переменная | Непрерывная: стоимость дома в долларах США |
| Пропущенные значения | Присутствуют (до 99% в некоторых столбцах) |
| Типы признаков | Количественные, категориальные, порядковые |

Решение задачи регрессии основано на комплексном подходе: предобработка данных, генерация новых признаков, вклчюая логарифмическое преобразование целевой переменной в силе большой асимметрии её распределения, обучение трех регрессионых моделей и их стекинг.

### Технологический стек

- **Анализ данных:** `Pandas`, `NumPy`
- **Визуализация:** `Matplotlib`, `Seaborn`
- **Предобработка и feature engineering:** `Scikit-learn`
- **Моделирование:** `XGBoost`, `LightGBM`, `Scikit-learn`

## 2. Подготовка данных и EDA

- **Обработка пропусков:** раздельно для каждого типа признака:
  - `PoolQC`, `MiscFeature`, `Alley`, `Fence` → замена на `"None"` (отсутствие объекта).
  - `Garage*`, `Bsmt*` → замена на `"None"` или `0`.
  - `LotFrontage` → медиана по `Neighborhood`.
  - Остальные → мода или медиана.
- **Анализ выбросов:** удалены дома с высокой площадью `GrLivArea` и низкой ценой.
- **Преобразование целевой переменной:** применено `log1p(SalePrice)` для устранения большой асимметрии распределения.
- **Кодирование категорий:** One-Hot Encoding.
- **Генерация признаков:**
  - Суммарная площадь (`TotalSF = TotalBsmtSF + 1stFlrSF + 2ndFlrSF`)
  - Возраст дома (`YearBuilt -> Age`)
  - Количество ванных, полных/частичных (`TotalBathrooms`)
  - Бинарные признаки (наличие гаража, бассейна и т.д.)
  - И прочие

## 3. Создание модели и валидация
Итоговая модель давала предсказание на основе трех базовых моделей XGBoost Regressor, Random Forest Regressor и Gradient Boosting Regressor, предсказания которой, как метапризнаки, подавались на вход модели линейной регрессии. Это так называемый подход стекнига.

Все модели обучались на одинаково предобработанном датасете.
Использовалась кросс-валидация (`KFold(n_splits=5)`), метрика — MAE.
Гиперпараметры оптимизированы с помощью GridSearchCV библиотеки Scikit-learn.
Финальный прогноз достигался посредством ансамбля, полученного стекингом
Итоговая модель показала неплохой результат (топ 15% в топе Kaggle)
